# Bhonduu's 19th Birthday Website — from Plipplop ♡

A responsive front-end birthday website with a burgundy scrapbook aesthetic, cream paper,
handwritten accents, interactive surprise reveal, love letter, editable captions, and photo frames.

## Preview
Open `index.html` in a modern browser. No build tools or backend are required.

## Personalize further
- The site is already personalized with the names Bhonduu and Plipplop.
- Edit birthday messages and the letter in `index.html`.
- Select up to six photos in the memory section when previewing the site.
- Captions can be edited directly on the page.
- Reference images are in `assets/`.

This is a front-end UI prototype only; it does not include a backend or hosting.
